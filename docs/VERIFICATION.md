# 验证记录

日期：2026-11-03。本项目由AI辅助检索、原创写作、实现与交叉审读，核查范围是所列公开资料。

## 内容与引用

36篇、180个正文段落，114条故事内来源记录、111个不同URL。检查覆盖重复ID、主题与地区枚举、年代范围、经纬度、段落/年表sourceIds、来源协议及本地资源存在性。

分工撰写后另作交叉审读，其中港岛及现代/食物16篇独立回到关键机构原文抽核。已更正SARS病毒名称的歧义、纪念碑标题的时间暗示、旧址/现址与繁简查询等问题；万宜1978/1979、火灾统计等分歧保留在各篇说明。撰写时所读资料的支持范围与查阅限制见 RESEARCH.md 和各篇来源表。

## 实际执行的验证

本会话云环境在container_creation阶段失败，无法本地启动预览；随后在GitHub Actions的Ubuntu24.04、Node22、Playwright1.56.1 / Chromium环境中运行真实浏览器验证。

- 结构检查：36篇正文、引用、坐标、年代和JS语法。
- 内容一致性：可编辑JSON、离线JS、GitHub阅读版逐段一致。
- 筛选：地域/主题/关键词/年代交集、反向年份、收藏与未读组合、阅读路线顺序、典型繁体地名。
- 安全显示：HTML转义与来源URL仅允许HTTP/HTTPS。
- 桌面浏览器：默认离线地理、聚合地点、故事阅读、段落出处、收藏/已读持久保存、时间线、记忆卡、路线及深链。
- 地图入口：逐一确认所有标记中心可直接命中自身，36个故事恰好各归一个分组；实际点击聚合点选择故事，并直接点击单一地点进入故事。切换视图并筛选后，地图标记保持正确尺寸。
- 网络中断：阻止所有HTTP/HTTPS请求，故事和离线地图正常；联网底图失败后返回离线模式。
- 手机390×844：阅读器、版面宽度、地图标记实际像素尺寸、模态背景隔离及键盘焦点。
- 单文件：与源文件构建输出逐字一致，并在网络被阻止时实际打开。
- 存储受限：拒绝localStorage时，地图和36篇故事仍能载入。

最终通过记录：[GitHub Actions #6](https://github.com/hongjinrui/ToKnow_Hongkong/actions/runs/41576801733)。应用及验证提交：9905485d2a2d777ce4eda4870cbfcf5dbabb696a。桌面与手机截图已实际查看，并保存于 docs/previews/。初次测试因ubuntu-latest已更新至Playwright不支持的26.04而未运行浏览器，已固定Ubuntu24.04并重跑通过。

更严格的地图直接点击测试曾发现网格分组跨格遮挡，现已按实际屏幕距离迭代合并，并验证全部标记中心的可点击性。也修正了在隐藏视图筛选后返回地图的尺寸计算。最终检查通过后仅补入本验证记录和README截图，应用文件保持该次通过的状态。截图是实际浏览器结果，不是设计稿。

## 验证边界

自动测试验证的是内容结构和用户操作流程；历史解释的范围由各篇文献支持，测试不能替代史料批判。地图采用2017年概化轮廓；并未测绘复原各年代岸线。未逐项实地踏查，未在Safari/Firefox或真实手机硬件上运行同样测试。默认离线模式已验证，可选街道底图主要验证载入失败的降级，外部瓦片的持续服务不由本项目保证。
